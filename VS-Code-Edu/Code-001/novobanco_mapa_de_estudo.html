Hook useToast

export function useToast() {
  const [toast, setToast] = useState(null);

  const showToast = useCallback((msg, type = "success", dur = 2800) => {
    setToast({ msg, type });
    setTimeout(() => setToast(null), dur);
  }, []);

  return { toast, showToast };
}

Hook personalizado que encapsula a lógica de notificação temporária. useCallback evita recriação da função a cada renderização.

React 18

Biblioteca para construir interfaces com componentes reutilizáveis. No projeto, o estado e os eventos são gerenciados com hooks.

Hooks usados

  • useState — estado local e global
  • useCallback — memo de funções
  • Customizado: useToast

Padrão

Componentes funcionais com JSX. Props passadas de pai para filho. Callbacks para comunicar filho → pai.

Vite 5

Ferramenta de build moderna e rápida. Substitui o Create React App no ecossistema atual.

Comandos

npm run dev → servidor local
npm run build → gera dist/
npm run preview → testa o build

Plugin usado

@vitejs/plugin-react — transforma JSX para JS e habilita o Fast Refresh (hot reload).

Capacitor 6

Ponte entre o web app (React) e as APIs nativas do Android/iOS. A WebView carrega o dist/ gerado pelo Vite.

Plugins nativos

  • @capacitor/status-bar — barra de status
  • @capacitor/keyboard — teclado nativo
  • @capacitor/haptics — vibração
  • @capacitor/app — ciclo de vida

react-chatbotify

Biblioteca de chatbot interativo usada na tela de Suporte. O fluxo de conversa é definido como um objeto JS com estados e transições.

Fluxo

Cada chave do objeto flow é um estado. O campo path decide para qual estado ir com base na resposta do usuário.

Passo a passo detalhado

1

Instalar dependências

cd banco-app && npm install

Instala React, Vite, Capacitor e todos os plugins de uma vez.

2

Desenvolver no navegador

npm run dev

Abre o app em http://localhost:5173 com hot reload.

3

Gerar o build de produção

npm run build

Vite compila tudo e gera HTML+JS+CSS otimizados em dist/.

4

Sincronizar com o Android

npx cap sync android

Copia o dist/ para dentro do projeto Android e atualiza os plugins nativos.

5

Abrir no Android Studio e gerar APK

npx cap open android

No Android Studio: Build → Build Bundle(s)/APK(s) → Build APK(s). O arquivo fica em android/app/build/outputs/apk/debug/app-debug.apk.

Atalho: npm run build:android faz os passos 3 e 4 de uma vez.
